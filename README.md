# Подход — дневник тренировок

Приложение для тренировок дома, в зале и для единоборств. Работает в браузере и ставится на телефон как приложение.

**Открыть:** https://pomonomarevmihail-web.github.io/podhod/

## Что умеет

- Генератор тренировок: дом, зал, бокс и кикбоксинг — каждый раз новая программа под уровень, время и инвентарь.
- 10 методик: классика, круговая, суперсеты, пирамида, лесенка, EMOM, AMRAP, табата, сила 5×5, раунды.
- Испытания для каждой темы оформления и план тренировок на неделю.
- 119 упражнений с фото, пошаговой техникой, частыми ошибками и вариантами «проще / сложнее» — в том числе становая сумо, гиперэкстензия, австралийские подтягивания, отжимания в стойке на руках, трастеры и икры.
- Жёсткий режим: 4–6 подходов на упражнение, короткий отдых и «добивка» в конце — последнее упражнение на пределе. Тренировка всё равно укладывается в выбранное время.
- Для 23 самых частых упражнений — настоящее короткое видео выполнения (не анимация): приседания, отжимания, подтягивания, становая тяга, жимы, тяги и другие. Видео грузится по требованию, чтобы не занимать место офлайн, а потом остаётся доступным без сети.
- Фото прогресса «до/после» — отдельная вкладка с сравнением на слайдере. Хранятся только на устройстве.
- Проведение тренировки: подходы, вес, таймер отдыха, раунды с гонгом и подсказками комбинаций голосом.
- Таймер: раунды, интервалы (Табата), отдых, секундомер.
- Питание: калории, белки, жиры, углеводы, вода.
- Прогресс: вес и замеры, график силы по каждому упражнению, отчёты, ранги, награды.
- Кнопка затмения в шапке: нажмите — начнётся кровавое затмение.
- Оформление «Берсерк: тьма», «Берсерк: тушь», «Рокки», «Космодесант» или «Классика», гравюры Дюрера, Доре и Гольбейна, архивные фото NASA, можно поставить свой фон. Мотивационные фразы написаны для приложения.
- Заминка и растяжка на 5 минут после любой тренировки.
- Таймер пробежки: время, дистанция, темп.

## Как поставить на телефон

- **Android (Chrome):** откройте ссылку → меню ⋮ → «Установить приложение».
- **iPhone (Safari):** откройте ссылку → «Поделиться» → «На экран Домой».

Записи хранятся на устройстве. Резервную копию можно скачать и загрузить в профиле.
